# 子&然 小窝 💕 使用手册

> 两个人的积分小窝 —— 把日常甜蜜变成看得见的积累

---

## 这是什么？

「子&然 小窝」是一个只有你和 TA 两个人使用的微信小程序。你们可以通过日常互动赚取积分，用积分兑换心愿和奖励，让每一天的甜蜜都被记录下来。

---

## 怎么开始？

1. **打开小程序**，用微信一键授权头像和昵称
2. **输入房间号**（4-12 位数字，自己定），再设一个 4-6 位数字的密码
3. 把房间号分享给 TA，TA 输入相同号码就能加入
4. 两人都加入后，各自获得 **100 初始积分**，开始你们的甜蜜积累

> 密码仅在兑换商城商品、领取/取消心愿时使用，日常加分扣分不需要密码。

---

## 积分怎么玩？

### 🎁 赚积分

| 方式 | 说明 |
|------|------|
| **给 TA 加分** | 给 TA 加 10 分，TA 得 10 分，你也得 3 分好人卡奖励 |
| **每日签到** | 每天签到得 10 分（心情好时翻倍） |
| **每日惊喜任务** | 两人都完成当日小任务，各得 20 分 |

### 💰 花积分

| 方式 | 说明 |
|------|------|
| **心愿小金库** | 创建心愿，设定目标和出资比例，赚到的积分自动攒进去 |
| **即刻兑换商城** | 直接花积分兑换奶茶、按摩、电影等奖励 |

---

## 四大功能页

### 🏠 家

打开小程序看到的第一页，包含：

- **我的积分 & TA 的积分** — 数字滚动展示
- **今日心情系数** — 显示今天的赚分倍率（0.8x ~ 2.0x）
- **每日签到** — 点一下领积分
- **快捷加分** — +5 / +10 / +20 一键给 TA 加分
- **今日惊喜** — 每天一个小任务，拍照打卡
- **冷暴力预警** — 3 天没互动会出现乌云提醒

### 💪 赚

专门给 TA 加分或扣分的页面：

- 选金额（5/10/20/50 或自定义）
- 选理由（夸夸宝贝、做顿饭给我吃、陪我逛街……12 种可选，也支持自定义）
- 加分不用密码，确认即生效
- 加分成功有全屏爱心撒花特效 🎉

### 🌸 花

管理心愿和兑换奖励：

**心愿小金库**
- 创建心愿（比如"看演唱会"），设定目标积分和各自出资比例
- 之后每次赚积分，系统自动按比例存入小金库
- 攒满了输入密码确认领取，触发撒花庆祝
- 不想要了可以取消，已存的积分退回

**即刻兑换商城**

| 商品 | 积分 |  |
|------|------|--|
| 🧋 奶茶一杯 | 30 | |
| 💆 按摩30分钟 | 40 | |
| 🏃 背我上楼 | 50 | |
| 🎬 看一场电影 | 80 | |
| 🕯️ 烛光晚餐 | 150 | |
| 🌊 周末短途游 | 300 | |

> 心情不好的第二天，所有商品半价！这是给你们的弥补机会。

### 👤 我

个人中心和数据：

- **睡前心情** — 每晚打个 1-5 星，影响明天的积分系数
- **积分明细** — 最近 30 条收支记录
- **互动热力图** — 最近 84 天的互动频率，像 GitHub 贡献图
- **冷暴力预警** — 超过 3 天没互动会显示提醒

---

## 情绪气象台 🌤️

每晚在「我」页面记录今天的心情（1-5 星），第二天会产生不同效果：

| 昨晚心情 | 今天效果 |
|----------|---------|
| 双方都 5 星 ⭐⭐⭐⭐⭐ | 赚积分 **翻倍**（2x）|
| 心情不错（3-4 星） | 赚积分略多（1.15x ~ 1.5x）|
| 有人打了 1 星 ⭐ | 商城兑换全部 **半价** |
| 没记录 | 正常（1x）|

> 所以，好好对待每一天，积分也会更多哦。

---

## 每日惊喜任务 🎲

每天系统会随机抽一个小任务，比如：

> 亲一下 · 倒杯水 · 夸我一句 · 捶捶背 · 抱抱30秒 · 讲个笑话 · 唱首歌给我听 · 拍一张合照……

两人都需要拍照打卡完成，都完成后各得 20 分。

---

## 冷暴力预警 ☁️

如果你们连续 3 天没有任何积分互动，首页会出现一朵灰色乌云，提醒你们该"发糖"了。可以点击乌云给 TA 发一条提醒消息。

---

## 小贴士

- **加分不需要密码**，只有兑换商品和领取心愿才需要
- **两人操作实时同步**，你加分后 TA 那边立刻能看到
- **退出小窝不会丢数据**，重新输入相同房间号就能恢复
- **密码可以修改**，在「设置」页面操作
- **心愿可以取消**，已存入的积分会原路退回
